¿Qué es una entidad?
Una entidad es una clase comun que en java, que representa una tabla en una base de datos.
¿Qué hace @Entity?
Sirve para demostrar que una clase java representa una tabla en una base de datos.
¿Qué hace @Table?

Sirve para conectar una clase java con una tabla especifica en la base de datos.

¿Qué es una Primary Key?
Es una llave con la que se relacionan las tablas
