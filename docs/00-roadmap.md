# Interview Coach IA

## Objetivo del proyecto
Construir una plataforma para entrevistas con modelos de IA

El sistema permitira:
- Registrar usuarios.
- Crear entrevistas.
- Cargar CV.
- Cargar descripcion JOB.
- Subir transcripciones.
- Analizar entrevistas con IA.
- Generar reportes.
- Mostrarla evolución del candidato.

## Tecnologías
- Java 21.
- Java Spring Boot.
- Maven.
- Spring Data JPA.
- MySQL.
- Validation.
- Lombok.
